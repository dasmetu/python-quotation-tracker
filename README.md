# Quotation Tracker

A Python-based quotation tracking application.

## Features

- Add quotations
- Display quotations
- Search quotations
- Update quotations
- Delete quotations
- Input validation
- Duplicate quotation number prevention
- JSON data storage

## Project Structure

- `main.ipynb` - Main program
- `validation.py` - Input validation functions
- `quotation_manager.py` - Quotation management functions
- `storage.py` - Loading and saving quotation data
- `quotations.json` - Stored quotation data

## Status

Prototype / learning project.
